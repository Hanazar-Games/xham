# 2 dimention

hanazar 的二次元中心，一个类似 Kahoot 的中文 Quiz 小游戏。v0.6.0 全站围绕动漫展开：6 个专区、12 套简单／困难题库、144 道配图题。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。

```sh
npm test        # 计分、暂停、超时、音频生命周期与题库校验
npm run build  # TypeScript 检查与生产构建
npm run preview
```

浏览器回归使用 Playwright Chromium，包含完整答题、响应式布局、无障碍和真实音频检查：

```sh
npx playwright install chromium  # 首次安装测试浏览器
npm run test:e2e                 # 自动构建后测试生产页面
```

测试使用本地 4175 端口，结果写入系统临时目录，不保存游戏会话到仓库。

## 已有功能

- 动漫专区浏览、搜索、难度筛选、难度排序、随机挑战、会话内收藏。
- 吉卜力电影、Re:0、芙莉莲、鬼灭之刃、海贼王、火影忍者各有简单与困难两套 12 题试卷；144 道二次元题全部配图，附剧透范围和资料链接。
- 专区、难度和关键词组合筛选，支持中英文别名；从专区退出挑战后保留筛选条件。
- 二次元简单题每题 20 秒，困难题每题 30 秒；支持点击或键盘 1–4 作答，重复提交被锁定。
- 答对获得 `round(500 + 500 × 剩余时间 / 总时间)` 分，答错或超时为 0 分。
- 即时答案解析、成绩统计、逐题回顾、重新挑战和会话内挑战记录。
- 主动暂停、弹窗暂停、切换标签页自动暂停；恢复后不扣除暂停时间。
- 在挑战记录中重新查看成绩与逐题解析。
- 独立音效 / BGM 开关与音量调节，答题反馈、最后 5 秒提示及完成旋律。
- 桌面与手机布局、键盘焦点、原生对话框及减少动效偏好支持。
- 应用内最新版本公告与可展开的历史公告，公告版本直接读取 `package.json`。

## 结构与扩展

```text
src/
  data/quizzes.ts       # 动漫题库汇总
  data/anime.ts         # 二次元题库、图片及资料引用
  data/anime-adventures.ts # 鬼灭、海贼、火影题库
  data/anime-packs.ts   # 各作品新增难度卷，复用已有配图与资料
  data/anime-series.ts  # 专区名称、说明与搜索别名
  data/releases.ts      # 最新公告与历史公告
  types.ts             # 题目与 Quiz 类型
  game/engine.ts       # 独立、可测试的答题状态机与计分
  game/QuizGame.tsx     # 倒计时、暂停、作答与界面编排
  game/QuizResults.tsx  # 答题结束与历史记录共用的成绩、解析界面
  audio/engine.ts      # Web Audio 合成音效、循环音乐及资源清理
  audio/AudioProvider.tsx # 会话声音设置与页面可见性管理
  components/QuizMedia.tsx # 封面、题目图片及加载失败回退
  components/AnimeHub.tsx # 二次元中心、专区卡片与统计
  components/          # 题卡、SVG 插画、图标与对话框
  App.tsx              # 题库浏览与会话状态
  styles.css           # 响应式样式
```

每道题需要唯一 `id`、4 个不同选项、从 0 开始的正确答案索引和解析。二次元题库还需 `series` 标识、逐题图片与资料来源；新区在 `anime-series.ts` 注册。每个专区保留简单与困难两档。`npm test` 检查题库结构、难度覆盖和配图引用，图片来源必须记入清单。

当前为前端单人版本，无账号、后端或多人房间。收藏与成绩只保存在 React 内存中，刷新即清空，不写入仓库或浏览器存储。多人扩展需要新增服务端房间、实时通信及服务端计时和答案校验；当前客户端计分不能用作可信多人排行榜。

字体使用 Google Fonts，并提供系统字体回退。封面加载失败时使用故事书 SVG；二次元题库的 64 张官方图片转为本地 WebP（共约 1.93 MiB），游戏内无需请求外站图片。剧照保留画面，人物立绘和漫画完整展示，小尺寸头像使用 `scale-down` 避免过度放大。原始地址与版权信息见 [图片来源清单](public/images/anime/sources.json)；图片著作权属于各权利方。

题目支持可选的 `image`、`source`，题库支持可选的 `image`、`scope`。图片不可用时显示回退内容，所有题目均可凭文字回答。资料链接在答题后展示，避免提前透露答案。Re:0 仅考动画第 1–2 季（第 1–50 集），分别提供人物入门和加护、权能、圣域试炼考核；芙莉莲限第一季基础人物设定。

v0.5.0 新增题目使用已有、附来源的设定与官方图片，简单卷考人物和基本概念，困难卷侧重职责组合、因果辨析与师承关系。新增 72 题复用现有图片，不增加下载体积；未引入未经核实的新篇章剧情。

鬼灭之刃限立志篇，海贼王考伙伴与船只的基础设定，火影忍者限寻找纲手之前及该篇章的早期剧情。不同主题可能含角色身份剧透，开局前可查看各题库范围。

## 声音与交互

音效默认开启，背景音乐默认关闭。音频仅在用户点击或按键后初始化；不支持 Web Audio 的浏览器仍可静音答题。所有音效和音乐由本地 Web Audio 合成，无外部音频下载。切换到后台时静音，暂停挑战时停止 BGM；答题中的声音设置面板暂停计时，并允许试听音乐。

答案锁定后，解析与「下一题」自动进入视野，焦点移至「下一题」；可使用 1–4 作答、Enter 进入下一题、Esc 关闭弹窗并恢复挑战。关闭弹窗后焦点保留在打开它的按钮。每题有明确的正确答案文字，核心操作不依赖声音或颜色。移动端输入框避免 iOS 自动放大，小屏题库采用单列。

运行时只创建一个音频上下文，音符结束后断开节点，关闭音乐时停止调度，卸载时关闭上下文。单元测试覆盖暂停计分、异常题库和时间、重复提交、静音、后台暂停及音频清理。浏览器回归还检查整轮答题、声音开关、历史解析和 320–1440px 布局。

v0.2.1 将异步音频状态切换串行处理，延迟启动时只保留最近 400ms 的最新提示音；快速操作会平滑结束上一段音效，未来音符可直接静音取消，避免叠加或增益突变。弹窗只在从遮罩开始并结束的点击中关闭，内部拖动不会中断设置，关闭后焦点回到打开按钮。

v0.4.1 修复弹窗关闭后焦点被答题界面覆盖的问题，并让试听统一经过音频引擎的 400ms 过期机制，避免关闭设置后播放过期试听。
