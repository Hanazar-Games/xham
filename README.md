# 2 dimention

hanazar 的二次元中心，一个类似 Kahoot 的中文 Quiz 小游戏。v0.46.0 提供四十二个作品专区，每个 IP 50 题、简单／中等／困难三档，另有跨番联考 72 题，全站共 2172 道配图题。提供 132 套练习卷，并支持按 IP 生成模拟考试。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址（固定 `http://localhost:5174`，端口占用时会报错）。

```sh
npm test        # 计分、暂停、超时、音频生命周期与题库校验
npm run build  # TypeScript 检查与生产构建
npm run preview
```

浏览器回归使用 Playwright Chromium，包含完整答题、响应式布局、无障碍和真实音频检查：

```sh
npx playwright install chromium  # 首次安装测试浏览器
npm run test:e2e                 # 自动构建后测试生产页面
```

测试使用本地 4175 端口，结果写入系统临时目录，不保存游戏会话到仓库。

每道题需要唯一 `id`、4 个不同选项、从 0 开始的正确答案索引和解析。二次元题库还需 `series` 标识、逐题图片与资料来源；新区在 `anime-series.ts` 注册。每个专区覆盖简单、中等、困难三档。`question-banks.ts` 聚合练习题与 `bank-additions.ts` 的考试扩展题，单 IP 为 50 题；新增题必须提供难度、配图、解析与资料。`npm test` 检查题库结构、难度覆盖和配图引用，图片来源必须记入清单。

当前为前端单人版本，无账号、后端或多人房间。收藏与成绩只保存在 React 内存中，刷新即清空，不写入仓库或浏览器存储。多人扩展需要新增服务端房间、实时通信及服务端计时和答案校验；当前客户端计分不能用作可信多人排行榜。

字体使用系统字体，不依赖外部字体服务。封面加载失败时使用故事书 SVG；二次元题库的 64 张官方图片转为本地 WebP（共约 1.93 MiB），游戏内无需请求外站图片。剧照保留画面，人物立绘和漫画完整展示，小尺寸头像使用 `scale-down` 避免过度放大。原始地址与版权信息见 [图片来源清单](public/images/anime/sources.json)；图片著作权属于各权利方。

题目支持可选的 `image`、`source`，题库支持可选的 `image`、`scope`。图片不可用时显示回退内容，所有题目均可凭文字回答。资料链接在答题后展示，避免提前透露答案。Re:0 仅考动画第 1–2 季（第 1–50 集），分别提供人物入门和加护、权能、圣域试炼考核；芙莉莲限第一季基础人物设定。

## 声音与交互

音效默认开启，背景音乐默认关闭。音频仅在用户点击或按键后初始化；不支持 Web Audio 的浏览器仍可静音答题。所有音效和音乐由本地 Web Audio 合成，无外部音频下载。切换到后台时静音，暂停挑战时停止 BGM；答题中的声音设置面板暂停计时，并允许试听音乐。

答案锁定后，解析与「下一题」自动进入视野，焦点移至「下一题」；可使用 1–4 作答、Enter 进入下一题、Esc 关闭弹窗并恢复挑战。关闭弹窗后焦点保留在打开它的按钮。每题有明确的正确答案文字，核心操作不依赖声音或颜色。移动端输入框避免 iOS 自动放大，小屏题库采用单列。

运行时只创建一个音频上下文，音符结束后断开节点，关闭音乐时停止调度，卸载时关闭上下文。单元测试覆盖暂停计分、异常题库和时间、重复提交、静音、后台暂停及音频清理。浏览器回归还检查整轮答题、声音开关、历史解析和 320–1440px 布局。

v0.2.1 将异步音频状态切换串行处理，延迟启动时只保留最近 400ms 的最新提示音；快速操作会平滑结束上一段音效，未来音符可直接静音取消，避免叠加或增益突变。弹窗只在从遮罩开始并结束的点击中关闭，内部拖动不会中断设置，关闭后焦点回到打开按钮。

v0.4.1 修复弹窗关闭后焦点被答题界面覆盖的问题，并让试听统一经过音频引擎的 400ms 过期机制，避免关闭设置后播放过期试听。

### 静态部署

开发：`npm run dev`，访问 http://localhost:5174/。请勿直接发布源码根目录。

GitHub Pages 使用 GitHub Actions 作为 Source；工作流测试通过后构建并上传 `dist`，自动匹配项目路径。其他子目录部署使用 `npm run build -- --base /子目录/`，发布 `dist`。

`npm run test:deployment` 使用无 SPA 回退的静态服务器验证 `/xham/` 下入口、全部图片、图标、来源页及答题流程。

## IP 模拟考试

进入作品专区，选择考试难度与题数，再生成试卷。二十三个作品 IP 各 50 题，分布为简单 18／中等 17／困难 15；每题限时分别为 20／25／30 秒，混合卷统一 30 秒。跨番联考的 72 题也可组卷。

- 支持 10 题、20 题、当前范围全部题，超出可用题数的选项禁用。
- 混合卷轮流从各难度抽取，不足的难度跳过；题目无重复，题序和选项随机且保留正确答案映射。
- 选择后锁定，不回改；超时记未作答，允许暂停。交卷前不通过颜色、分数、提示音或链接公布答案。
- 百分制分数为 `round(答对数 / 总题数 × 100)`，60 分及格，无速度奖励；成绩页提供分难度表现及全部解析。
- 重做本卷保留题目与顺序；返回专区生成新的随机卷。记录只保留在当前访问内。
- 30 套练习卷提供逐题讲解，使用原速度计分规则。挑战记录按最高正确率汇总，避免比较不同计分制的原始分数。
