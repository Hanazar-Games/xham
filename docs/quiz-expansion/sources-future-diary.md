# 未来日记核验记录

核验日期：2026-09-21。对应清单#39《The Future Diary》，限定2011–2012年电视动画正篇第1–26集与官网人物、日记规则；不含Redial、真人版或漫画版结局。含持有者身份、日记弱点与世界重启剧透。

## 官方人物与规则

- [1st 天野雪辉](https://future-diary.tv/chara/1st.html)：无差别日记、主观观察造成的误差、飞镖特长。
- [2nd 我妻由乃](https://future-diary.tv/chara/2nd.html)：雪辉日记每10分钟记录，与无差别日记的信息互补。
- [3rd 火山高夫](https://future-diary.tv/chara/3rd.html)：教师身份，杀人日记对目标外意外事件的盲点。
- [4th 来须圭悟](https://future-diary.tv/chara/4th.html)：刑警、搜查日记的辖区和犯罪调查范围限制。
- [5th 丰穰礼佑](https://future-diary.tv/chara/5th.html)：绘画日记只显示早午晚三次。
- [6th 春日野椿](https://future-diary.tv/chara/6th.html)：御目方教、千里眼日记仍受信徒视角约束。
- [7th 战场马克](https://future-diary.tv/chara/7thm.html)、[美神爱](https://future-diary.tv/chara/7tha.html)：交换日记记录彼此，分开行动削弱配合。
- [8th 上下灶](https://future-diary.tv/chara/8th.html)：母之里院长、增殖日记本体为可穿戴服务器。子日记对应官网「孫日記」，手机损坏不会让持有者消失，但失去与本体的连接便无法使用。
- [9th 雨流美弥音](https://future-diary.tv/chara/9th.html)：逃亡日记。
- [10th 月岛狩人](https://future-diary.tv/chara/10th.html)：猎犬的命令与回应、日向的父亲。
- [11th 约翰·巴克斯](https://future-diary.tv/chara/11th.html)：市长，The watcher可查看所有未来日记内容，不等于改写能力。
- [12th 平坂黄泉](https://future-diary.tv/chara/12th.html)：录音机形式的正义日记，善恶由其主观判断。
- [德乌斯](https://future-diary.tv/chara/deus.html)：时空王、生存游戏主办者。
- [姆鲁姆鲁](https://future-diary.tv/chara/murmur.html)：侍从身份与独自行事的迹象。
