# 第96–100项题库核验

核验日期：2026-10-04。五部各50题，简单18／中等17／困难15；每部三套12题练习，剩余14题进入完整考试池。题目为根据下列资料重新编写的中文四选一，含剧透。

## #96 无头骑士异闻录!! 第一季

范围：2010年电视正篇第1–24集，不含12.5、25集番外、×2续作或小说后续。

- [第一季剧情目录](https://www.durarara.com/1st/story/)与`story01.html`至`story24.html`：逐集读取剧情正文，核对帝人入城、失踪调查、集会、罪歌、黄巾贼冲突。
- [第一季人物页](https://www.durarara.com/1st/chara/)：读取页面嵌入的`assets/img/character/detail/i0.jpg`至`i11.jpg`人物卡，核对姓名、关系、职业和同班身份。人物介绍文字位于图片中。

重点：第13集是Dollars集会半年后；第14、20集的“组织中有砍人魔”属于角色当时的怀疑；记者先广泛询问“池袋最强”，第15集才聚焦静雄力量的秘密。未把官网四字熟语示例小剧场当成动画剧情。

数据引用：1–24对应分集；`characters`对应第一季人物卡。

## #97 辉夜大小姐想让我告白 第二季

范围：2020年第二季第1–12集与该季人物、音乐资料，不含OVA、第三季、电影或漫画后续。

- [第二季剧情](https://kaguya.love/2nd/story/?id=01)：逐页读取`?id=01`至`?id=12`；题目采用已公开的非性化情节，不从短篇标题推断正文没有说明的事件。
- [第二季人物页](https://kaguya.love/2nd/character/)：伊井野的年级、会计监察／风纪委员身份、家庭与钢琴经历，大佛与她的旧交。
- [片头曲资料](https://kaguya.love/2nd/music/opening/)：DADDY! DADDY! DO!，铃木雅之／铃木爱理、水野良树、本间昭光。
- [片尾曲资料](https://kaguya.love/2nd/music/ending/)：風に吹かれて，福原遥、小倉しんこう、梅原新；福原遥兼任子安燕配音。

重点：伊井野竞选时邀请藤原担任副会长，与她自己加入后的会计监察职务不同；石上替受伤团长跑最后一棒；辉夜受限的是公开媒体露脸，私人合照的意义是留下共同回忆。日文歌曲名按原文保留。

数据引用：1–12对应分集；`characters`对应人物页；101片头曲、102片尾曲。

## #98 化物语

## #99 哈尔的移动城堡

范围：2004年动画电影的公开剧情及制作、美术知识。VIZ电影漫画是对电影的再呈现，不能当作电影之前的漫画原作；不引入小说独有设定。

- [VIZ系列介绍](https://www.viz.com/howl-s-moving-castle)：苏菲对自己的看法、蕾蒂、帽子店。
- [电影漫画第1卷](https://www.viz.com/manga-books/film-comic/howls-moving-castle-film-comics-volume-1-0/product/506)：士兵纠缠、荒野女巫施咒、进入城堡。
- [第2卷](https://www.viz.com/manga-books/film-comic/howls-moving-castle-film-comics-volume-2-0/product/507)：清洁工作、住户相处、魔法师变成怪物参战。
- [第3卷](https://www.viz.com/manga-books/film-comic/howls-moving-castle-film-comics-volume-3-0/product/508)：代答王室召见、导师莎莉曼、女巫住进城堡。
- [第4卷](https://www.viz.com/manga-books/film-comic/howls-moving-castle-film-comics-volume-4-0/product/509)：追踪、搬家、回到帽子店、城镇上空的战争。
- [官方电影美术书](https://www.viz.com/manga-books/art-book/art-of-howls-moving-castle/product/510)：19世纪欧洲科学与魔法并存的视觉想象、美术材料和制作访谈。

数据引用：1作品页，2系列介绍，3–6电影漫画1–4卷，7美术书，8与9分别为2024／2022年NTV介绍。

## #100 冰菓

范围：2012年电视动画第1–22集及京阿尼人物与制作访谈，不含11.5集OVA、小说后续。

- [京阿尼故事总览](https://www.kyotoanimation.co.jp/kotenbu/story/)及`story/01/`至`story/22/`：校园、古典部、45年前旧事、学生电影、文化祭、直升机、校内广播、新年、巧克力与生雏祭。
- [人物页](https://www.kyotoanimation.co.jp/kotenbu/character/)：读取奉太郎、爱瑠、里志、摩耶花的`profile.png`图文资料。
- [制作名单](https://www.kyotoanimation.co.jp/kotenbu/staff-cast/)：原作者米泽穗信、音乐田中公平。
- [逐集制作访谈](https://www.kyotoanimation.co.jp/kotenbu/interview/)：逐段区分正片回顾与作者玩笑、未采用的设计及个人感想。

访谈用于补核：第5集关谷纯形象不预先固定、第7集浴衣影子与广播体操、第8集实拍参考与3D废墟、第11集伙伴质询中的关怀、第13集漫画书、第15集奇术部埋伏、第17集车棚光线、第18集图书馆报道、第19集爱瑠记下广播、第20集摩耶花巫女装／小屋／里志开门、第21集巧克力消失、第22集樱花首尾呼应。未采用第6、12、16集访谈中的虚构玩笑对话或假标题。

重点：历史年代使用电视版的45年前；“数据库”是里志的自称；旧老师的爱好先是奉太郎的记忆，随后被同学的不同记忆动摇。

数据引用：1–22对应分集；`characters`人物页；101总览、102制作名单、103逐集访谈。

## 配图与复核

每题均使用本地原创SVG主题示意图；新增`urban-rider`、`student-council`、`oddities`、`walking-castle`、`anthology`五幅，并复用既有主题插画。图片不是官方剧照，也不是每题独占的插画；来源和替代文字均明确说明。人物卡图片只用于临时核查，不随站点发布。

二次复核收紧了干扰项，统一日文歌名与制作人员署名，核对角色行动的动机、推测与结果。题数、唯一题干、四个不同选项、难度配比、图片、来源和练习／考试完整覆盖由回归检查验证。研究缓存与浏览器状态仅存系统临时目录。
