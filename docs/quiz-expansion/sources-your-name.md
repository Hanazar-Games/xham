# 你的名字。：来源与题库范围

核验日期：2026-09-19。对应清单#12，50题，简单18／中等17／困难15。

专题为2016年动画电影的人物关系、交换生活与制作知识，包含人物关系和交换中断剧透。公开剧情简介没有展开后半段精确时间线、救援方案及结局，本批不考这些细节，不以记忆补齐答案。50题代表这一专题的可玩题量，不代表逐场景穷尽电影剧情。不混用小说扩写、漫画版或其他电影。

出版方专题页和广播方页面本轮未取得可读补充正文，未用作来源。没有引用未读取的小说正文或未核实的后半段细节。

## 自查重点

- 四叶的“四年级”来自角色资料，不是演员年龄；早耶香姐姐负责广播不等于早耶香本人任职。
- 好感关系有方向，不能把早耶香喜欢敕使河原直接推成当时已互相表白。
- 备忘沟通并不表示能任意控制交换时刻或自动记住对方全部经历。
- 区分人声歌曲4首与配乐22首、角色设计与作画监督、剧本基本方向固定与最终完成。
- 每题使用本地原创SVG主题示意图，有复用，非官方剧照；三套练习36题，其余14题进入考试池，共50道唯一题目。
