# Overlord 第一季资料核验

## 范围与方法

清单 #69独立50题，简单18／中等17／困难15。限定2015年第一季第1–13集官网公开简介和人物资料，不混入第二季及后续季度、剧场版或原作差异。读取日期：2026-09-22。

依据用户既有授权直接核查作品官网。没有重新观看正片，没有以百科、评论或记忆补写技能数值及最终制胜细节。配图为项目可复用原创主题SVG，不是官方剧照或逐题专属角色画；官方图片仅供事实核验，未入库。

## 已读取资料

- [第一季故事页](https://overlord-anime.com/_season1/story.html?st=1)：页面脚本由 `assets/outline/0.js` 至 `13.js` 加载正文，已实际读取故事概述及全部13篇分集简介。题目来源使用官网可导航的 `story.html?st=N`，不把空的加载容器当作正文。
- [第一季人物页](https://overlord-anime.com/_season1/character.html?c=3)：介绍以图片呈现，实际查看编号1、2、3、4、5、6、7、9，分别为飞鼠／安兹、雅儿贝德、夏提雅、亚乌菈、马雷、迪米乌哥斯、科塞特斯、娜贝拉尔。本文使用的独立人物题仅引用3–7，核对真祖吸血鬼、黑暗精灵、双胞胎关系与第五至第七层守护者身份。

## 题号与证据

- 1–5、11–18：第1–8集人物、地点与身份信息，具体集数写入每题来源。
- 6–10：官网人物编号3–7的种族、亲属与职务资料。
- 19–35：第3–13集，登记铜级、巨剑、远隔视之镜、阳光圣典、村庄变化、身份推断、墓地战分工、捕获任务及复活规则。
- 36–50：第2–13集的动机、信息与战斗条件判断，均限定简介所明示的事实。

## 关键边界

第6集对精钢级的比较是同行者感叹，不是已登记升阶。第9集明确高身体能力来自等级补正，却没有剑士技能。第10集捕获特殊能力者的目标与失控漏敌须分开。第11集神器级武器只证明出现异常事态，不足以推知对方所有细节。第12集说明旧游戏有复活魔法，但新世界能否使用尚未确认。第13集区别即死完全耐性、附加技能效果与复活道具，资源耗尽后的近身优势也不能直接写成最终获胜结论。
