# Another 电视版：来源核验

核验日期：2026-09-22。清单 #63，50题（简单18／中等17／困难15）。限定2012电视版第1–12集公开简介与制作公司资料，含事故、调查及合宿事件剧透，不混入OVA、真人电影、原著续作或漫画差异。公开简介未揭示的最终死者身份与结局机关不考。

已读取万代频道作品4255的[第1集](https://www.b-ch.com/titles/4255/001)至[第12集](https://www.b-ch.com/titles/4255/012)全部公开分集简介，以及[P.A.WORKS作品介绍](https://www.pa-works.jp/works/another/)的故事和制作名单。50题覆盖12个分集链接和制作公司页。旧站another-anime.jp无法取得正文，制作公司所链电视台旧地址也未取得有效作品页，没有将其列为事实依据。未采用平台用户评论。

核验重点：故事1998年与动画年份分开；26年前原始事件与15年前中途停止的事件分开；母亲与怜子各自的班级年份；水野职业、赤泽职务变化、千曳与松永的信息来源；旧校舍和录音带调查；合宿地点与引率者；怀疑鸣不等于已证实她的身份。事故只概述，不描写血腥细节。

困难题考查信息不对称、调查动机与线索边界，不把集体恐惧当作证据，不把找到录音带当作灾厄已经停止，不根据城外事故擅自补写完整地理规则。制作知识来自公司署名资料。

图片全部使用本地原创主题SVG，可复用，不是官方剧照或每题独占插画。三套12题练习和14道考试专属题组成50题池。第4段完成3／20，下一项为#64《Demon Slayer: Mugen Train》。
