# 盾之勇者第一季资料核验

## 范围与方法

清单 #67新增独立50题，简单18／中等17／困难15。限定2019年电视动画第一季第1–25集公开简介与人物资料，不混入第二季及后续季度、小说或漫画差异，不编造技能倍率或数值。读取日期：2026-09-22。

依据用户既有授权，直接读取作品官网和正版发行资料。没有重新观看正片，不使用用户评论、百科或未经核验的后续知识。配图为项目本地原创主题SVG，可复用，不是官方剧照或逐题专属人物画；未复制官网角色图片。

## 已读取资料

- [第一季官网](https://shieldhero-anime.jp/1st/)：实际正文集中在该首页，包含故事导言、第1–25集简介、人物与2019年影碟资料。读取尚文、拉芙塔莉雅、菲洛、炼、元康、树、梅尔蒂的人物介绍；核对高防低攻、风魔法、变身与四圣武器对应。尝试的 `/1st/story/` 没有有效正文，不作为证据。
- [万代频道第1集](https://www.b-ch.com/titles/6384/001)至[第25集](https://www.b-ch.com/titles/6384/025)：全部25篇标题与简介已读取，和官网内容交叉核对。第一季官网亦直接链接作品6384；后续季度的7711、8248、9224不用于本批。

## 题号与来源

人物资料用于第2、3、4、8、10、19、36题；其余题目分别关联数据中记录的第一季集数。数字来源直接生成三位分集URL，characters来源指向第一季官网。

- 1–18：身份、武器、书籍、龙刻沙漏、伙伴与海岛。
- 19–35：攻防、魔物蛋、装备适配、植物危机、龙尸、转职、追逃、教皇、审判与阵营揭示。
- 36–50：攻击手分工、变身与装备区别、战后善后、手续阻碍、局部救援与全局危机、诅咒盾、冤罪辨析、引敌疏散和阶段性共斗。

核验要点：第8集疫病来自已死1个月且未处理的龙；第10集等级提升不等于转职手续完成；第13集明确是遭到诬告而非已证实绑架；第16集引离城市不等于解决防御；第20集明确大圣堂中诅咒盾无效化及龙之怒侵蚀；第24集共斗不能外推为永久结盟，第25集另有阵营揭示。相关题均限定第一季时点。
