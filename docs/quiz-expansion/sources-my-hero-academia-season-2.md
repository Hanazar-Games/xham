# 《我的英雄学院》第二季核验

日期：2026-09-19。限定2017年第二季累计第14–38集，涵盖体育祭、职场体验、斯坦因事件与期末实技；不混用其他季度、OVA和剧场版。

- [读卖电视台剧情入口](https://www.ytv.co.jp/heroaca/story/)
- [页面实际读取的公开分集JSON](https://www.ytv.co.jp/heroaca/data/story.json)

核查官网 `js/story.js` 的加载与分集切换逻辑，读取JSON中 `season` 为 `第2期` 的25集正式简介。该页面默认展示最新内容，按BACK NUMBER第二季及累计集数查看；题目来源标签逐题标明集数，不伪造不会生效的直达参数。

发现第19集简介把轰的火焰写作右手；第17集写左手火焰、右手冰冻，第23集写左手解放火焰，第25集再次写左火右冰。因此题目按17、23、25交叉核验，第19集仅引用家庭目标，不引用错误左右关系。

50题：简单18、中等17、困难15。三套12题练习加14道考试专属题，每题使用复用的本地原创SVG示意图，非剧照。重点核验骑马战1000万积分、心操诱导回应、全覆盖遍布全身、无许可战斗的后果、诱饵船调查以及教师对双人学生的期末考核。

不补写未从简介核实的具体血型限制、精确输出百分比、后续能力升级或游戏设定。难题含基于明确剧情条件的推理，解析区分直接事实与战术判断。
