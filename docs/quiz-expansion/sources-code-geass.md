[第一季分集目录](https://geass.jp/first/story.html)提供1–23集独立页，以及[24、25集合页](https://geass.jp/first/story_2425.html)。独立页格式为 `https://geass.jp/first/story_NN.html`，NN为01–23。已逐页读取，网站使用日文CP932编码。8.5和17.5集回顾不并入25集正片范围。

- 7–13集：柯内莉亚的诱敌战术、河口湖人质、Refrain、红莲贰式、成田逆转、京都会面及夏莉卷入战场。
- 14–18集：毛的读心、C.C.的责任、娜娜莉限时救援、藤堂营救、Zero确认驾驶员身份与主动诱敌。

## 核查边界

- 第二集向观众说明朱雀驾驶兰斯洛特，第十七集Zero才在战斗中确认；不把观众信息当作角色当时已知信息。
- 朱雀被捕是嫌疑身份，不写成罪名已经成立；Zero获得释放机会后，朱雀仍选择前往法庭。
- 毛的能力为读思考，不混用鲁路修的能力效果。不依据简介猜写Geass距离、重复次数、失控细节等参数。
- 第19集区分式根岛与神根岛；第20集区分名义独立与受外国控制的政权。
- 第24集租界崩塌源于支撑结构破坏，不说成Geass控制重力。
- 第22–25集简介保留悬念，题目只采用明示事件；难题以这些条件进行战术推理，不补写完整悲剧过程或结局。

50题分为简单18、中等17、困难15；三套12题练习及14道考试专属题。全部使用项目已有原创主题SVG、附解析与具体分集来源，图片有复用。未下载或再发布本作官方剧照。
