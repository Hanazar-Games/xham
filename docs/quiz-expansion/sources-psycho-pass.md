# 心理测量者第一季资料核验

## 范围与方法

清单 #71独立50题，简单18／中等17／困难15。限定2012–2013年电视动画原版第一季第1–22集正版简介及富士电视台世界观介绍，不混入新编集版新增场景、第二季、剧场版或其他后续作品。读取日期：2026-09-22。

依据用户既有授权直接核查官方及正版资料。旧动画官网归档页面返回验证页，未把验证页当正文；改用电视台、制作方与正版平台可访问资料。没有重新观看正片，不使用用户评论或百科，不补写未核验的数值阈值、系统内幕及完整结局。

## 题号与证据

- 1–18：各分集简介的人物、职位、地点、虚拟形象与旧案；角色全名辅以电视台名单核对。
- 19–20：富士电视台世界观说明，明确职务分工与执行官风险。
- 21–35：第4–5、7、10–19集，身份矛盾、行动结果、通信限制、邀请意愿、目击、异常读数、组织命令与追踪目的。
- 36–50：第3–7、9–10、12、14–15、17–19、21–22集，围绕公开情节进行证据与条件判断。

工厂方坚持事故不等于死因已证实；虚拟形象的原操作者死亡不等于形象无法被别人使用。第12集弥生有执行官适性与最初拒绝邀请并存。第14集行为与读数矛盾不能抹去行为证据。第17集对縢的逃犯定性是组织说法，不是其失联全过程的已知事实。第19集声音是线索而非已确认实时位置，朱追踪狡啮的目的是阻止私刑。第22集简介以设问描述终局，不据此补写人物最终去向。
