# 野良神第一季：来源核验

日期：2026-09-21。清单 #28《Noragami》，限定2014年第一季第1–12集及同期人物设定，不混入Aragoto第二季、OAD或漫画后续。

- [第一季剧情页](https://noragami-anime.net/1/story.html)：`#headCts1` 至 `#headCts12` 是实际存在的分集区块。
- [第一季人物页](https://noragami-anime.net/1/character.html)：`#charaScr1` 至 `#charaScr10` 对应夜斗、日和、雪音、小福、大黑、毘沙门、兆麻、天神、野良和蠃蚌。

当前主站对应第二季。第一季桌面入口依赖Flash，但其移动入口 `/1/sp/index.html` 提供上述普通HTML链接。直接阅读12集简介和10个人物区块，逐题引用这些可读页的真实锚点，不使用不可播放的Flash入口。直接核查官方资料已获用户授权。

旧剧情页存在模板错误：后几集图片alt重复写第9集，并出现“2014年2月30日”等无效日期。核查采用正文、分集区块ID及对应图片文件编号，不依赖这些错误字段出集名或播出日期题。

重点区分：五日元是夜斗的委托香火钱；日和仍是活着的半妖，与雪音的神器身份不同；第5集是擅取滑板试玩，第6集才明确偷窃并撒谎；第9集禊需要三名神器，且目标是雪音忏悔，不能简化为任意三人到场。天神人物页对应菅原道真。野良侍奉多位神明，不能用单一主人概括所有神器。

蠃蚌的人物页明确标注“あだちとか先生原案”“TV动画原创角色”，因此最终两集按动画版出题，不推定漫画有完全相同事件。小福的“惠比寿”只按人物页考其自称，不把该自称当成真实身份证明。

50题：简单18、中等17、困难15，三套12题练习与14道考试专属题。每题有解析、来源及复用的本地原创SVG主题示意图，不打包官网剧照、立绘，不声称逐题独立插画。困难题主要考能力条件、行动因果与版本辨析。
