# 冰海战记 第一季：来源核验

核验日期：2026-09-22。清单 #62，50题（简单18／中等17／困难15）。限定2019年电视动画第一季第1–24集及官网第一季人物介绍，含父亲命运、复仇与王权斗争剧透。不混入第二季农场篇及漫画后续，不将作品剧情直接作为真实历史知识。

已读取万代频道作品7349的[第1集](https://www.b-ch.com/titles/7349/001)至[第24集](https://www.b-ch.com/titles/7349/024)全部公开简介，并读取[动画官网人物页](https://vinlandsaga.jp/character/)。人物页同时有两季资料，本批只取前部第一季的托尔芬、托尔兹、阿谢拉特、克努特、托尔克尔、比约恩介绍，排除后部农场篇人物与经历。逐题链接对应实际使用的分集或人物页，不使用平台用户评论。

核验重点：冰岛童年、文兰憧憬；托尔兹假死退隐与再度被迫出航；复仇和决斗奖赏；法兰克战场、日德兰过冬、伦敦桥阵营；塞文河与威尔士通行；追兵消息造成的军心变化；克努特作为投奔筹码；决斗中的临时共斗；王子的领导变化与舆论约束；末集的威尔士交涉与返乡准备。

个人实力不等于全员可安全撤离；临时合作不等于复仇矛盾已经和解；传闻带来的政治优势不等于最终胜利。瓦尔哈拉只作为人物信念，狂战士强化同时有失控代价。未从短简介的悬念补写末集终局行为。
