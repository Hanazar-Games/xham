# Re:0第一季独立题库核验

日期：2026-09-19。沿用用户授权直接读取动画官网，仅采用2016年第一季1–25集的公开剧情，不混入第二季、特别篇或新编集追加结尾。

## 来源

[官网第一季新编集版资料页](https://re-zero-anime.jp/tv/story/tv1r.html)保留各正片原集数的简介。本轮读取全部25集正文并检查HTML锚点。

- 第1–11集：锚点 `EP1` 至 `EP11`。
- `EP12` 是额外的11.5集《Memory Snow》，不用于本题库。
- 第12–25集：锚点 `EP13` 至 `EP26`，比正片集数多1；来源函数与测试明确校验这一偏移。
- 第1–4集：初来异界、循环地点、赃物库、帕克玛那消耗、徽章和王选资格。
- 第5–11集：宅邸循环、锁链声、保护期限、信任、诅咒检测、多重诅咒和魔兽救援。
- 第12–18集：贤人会、五位候选人、菲鲁特参选意愿、求援、龙车与白鲸、循环后的心理冲击。
- 第19–25集：白鲸时间地点情报、同盟谈判、帕特拉修、尤里乌斯合流、异常花朵、村民疏散及观察与战斗协作。

## 易混项与边界

- 早期赃物库循环、宅邸循环与水果店循环的重来地点不同，不把第一集的地点当作整季固定规则。
- 帕克玛那耗尽不代表敌人已被击败；多重诅咒无法直接解除不等于碧翠丝拒绝承认诅咒存在。
- 被保护到第五天，只是昴个人暂时存活，不能证明所有人的危机消失。
- 施咒者调查先有假说、再检测并发现误判，不把怀疑写成已验证事实。
- 第19集情报为时间与地点，可信与否、是否承担王选同盟风险是不同决策。
- 第25集是昴提供观察、尤里乌斯负责战斗；能力互补仍需要配合，不能写成无条件自动获胜。
- 不加入简介未明示的不可视之手参数、禁忌细则、回归检查点控制权等细节。困难题是资料支持下的条件分析，解析不宣称额外剧情。

## 与既有题库的关系

`rezero`保留为前两季综合题库；新`rezero-season-1`另写50题，按18／17／15分档，三套12题练习与14道考试专属题。仅新题库映射清单第23项，后续季度依然待制作。每题配本地原创主题SVG、解析和来源，图片有复用，不增加官方剧照。
