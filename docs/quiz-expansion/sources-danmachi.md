## 题目范围与重点

1–18为人物、眷族、怪物与基础地点。19–35为成长条件、队伍分工、角色动机、楼层与救援。36–50为信息边界、因果和探索条件；第50题对照第12、13集，说明常规安全地带与异常现身的区别。

- 第1集在第5层遭遇本不应出现的高等级怪物；第4集已达第7层；第10集第13层为中层难关；第12集第18层为安全地带，不互换楼层。
- 第2集憧憬一途：思慕持续且成长随思慕强度变化。没有固定倍数、升级天数或即时无敌保证，不补写技能数值。
- 第4集支援者负责杂务；第5集让贝尔更专注战斗并增加收入，同时莉莉仍有独立困境。
- 第6集魔导书使贝尔获得魔法，苏摩眷族狂热与奇迹美酒有关，两条线索不混同。
- 第9集弥诺陶洛斯战后升级、获得Little Rookie称号并遇到韦尔夫；只使用简介实际公开的内容，不猜等级参数。
- 第11集深入是危机下最后的艰难选择，物资枯竭、迷宫更复杂，不是已确认安全路线。
- 第12集不产怪的安全地带仍有嫉妒等人际风险。第13集冒险者纠纷平息后出现歌利亚，并引发联合应战；不将常规安全定义写成绝无例外。
