简单18、中等17、困难15题，三套12题练习加14道考试专属题。重点核验：

- 勘九郎的傀儡由蝎制作，机关信息影响战斗判断。
- 鼬与鬼鲛形貌的阻击者为象转替身，击倒不代表杀死本体。
- 据点结界必须同时揭下五张符，白眼定位不能替代同步行动。
- 绯流琥攻防一体且带猛毒，轻微擦伤亦有致命危险。
- 解毒有效约三分钟，不等于永久免疫或自动修复要害创伤。
- 千代十机与蝎百机的对应关系；小樱再次参战时药效已过。
- 凯班本体会疲劳，写身保持出现时的动作水平。
- 第29集空间转移效果与第30集抑制九尾暴走分开，不推入后续设定。
