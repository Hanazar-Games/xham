## 规则与推演边界

- 双重记忆翻牌：两副去掉JOKER共104张；数字和花色均相同才匹配，先拿54张／27组获胜。第37题额外限定公平随机、无位置信息及尚未移牌，首张之外103张只有1张同款。第38题为双方各26组的假设，只判断未达门槛，不杜撰加赛。
- 投票猜拳：当事人以外30位同学填写，双方各抽3张；三次平手记平局。
- 双牌印第安扑克：第一张自己看，第二张自己不看而给他人看；数字一致高于花色一致，同牌型才比较数字和。第39–40题用明确手牌检验判定顺序。
- 债务整理：每人10枚，每枚价值为自己的申报额除10，10轮且每轮1枚参加费，可使用他人筹码，按金额而非枚数排名。第41与43题使用题干给定金额，分别推导单枚价值和6000万大于5000万；不假定作品真实名次或最终债务分配。
- ESP：监控可见范围不对称；比较相同位置上的匹配数，差额为点数。第44题甲匹配1、4、5位，乙匹配1、2位，结果3比2、差1点。
- 选择扑克：53张含1张JOKER、5张手牌、仅一次换牌，无Call和Fold；出资更高者选择Stronger或Weaker。第45题以乙已获选择权并选Weaker为前提，不声称弱牌无条件获胜。
