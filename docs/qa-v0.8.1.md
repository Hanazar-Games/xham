# v0.8.1 深度检查记录

2026-09-17，检查题库与筛选、收藏、游戏状态机、成绩回顾、模态对话框、图片与音频生命周期。题库保持 22 套、264 题。

## 发现与修复

- 搜索框宣称支持角色与技能，但仅检索题库元信息：扩展到题干、解析及联考包含作品的别名，规范全角输入；索引在模块加载时生成。
- 手机搜索仍显示全部专区，结果位于长目录之后：搜索时收起目录，标题标明搜索范围；切换专区与重置筛选恢复可见的键盘焦点。
- 从收藏中途退出挑战会回首页：区分中途退出与成绩页探索，保留原视图、关键词、专区和难度，并定位到原题卡。
- 历史回看返回及回看中取消重玩丢失焦点：恢复原按钮；历史记录使用稳定的游戏 ID，防止重玩新增记录后定位到错误行。
- 空筛选的随机挑战悄悄退回全库：当前结果为空时禁用，保留明确标注的全站随机入口。
- 联考满分文案误称「这部作品」：改为适用于多作品的设定细节提示。
