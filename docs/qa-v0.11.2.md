# v0.11.2 检查记录

日期：2026-09-18。

## 范围与修复

复查应用导航、收藏、搜索、题库目录、练习、考试、成绩回顾、弹窗、计时、图片恢复、键盘操作及音频生命周期。重点检查 v0.11.1 的内容校验、同图换题、剧透范围和公告归档。

本次复现并修复三项问题：

- 图片临时加载失败后，本题没有重新加载入口。现可原地重试，重试失败仍可继续重试；焦点移至题图区域，题号、答案状态及倒计时不重置，文字明确提示重试不暂停计时。
- 清空搜索按钮从页面移除后，键盘焦点丢失。现返回搜索框，可立即继续输入。
- 中文输入法组合输入中的数字被当作答题快捷键，可能误提交答案。现忽略组合输入，正常 1–4 快捷键仍有效。

三项新增浏览器回归先在旧实现上失败，再验证修复。未改动考试计分、难度配比、题库事实或音频旋律。

## 验证内容

129 项单元测试、64 项 Chromium E2E、TypeScript 与生产构建、静态部署检查全部通过。补强计时连续性断言后另跑 4 项图片／键盘回归通过，320px 图片失败界面 WCAG AA 扫描无违规。

- 单元测试：题库数据与图片文件、完成判定、考试抽题、计分、音频异步状态与资源释放。
- 浏览器全流程：24 套练习、六个 50 题考试，覆盖全部 372 道题的图片解码、答案、反馈、成绩、重做与历史。
- 新增交互：图片重试成功／再次失败、焦点、计时连续性、中文输入法误答、清空搜索焦点；保留上一版同图换题恢复回归。
- UI/UX：320px 至 1440px 及横屏布局、无障碍扫描、长标题、目录搜索、弹窗焦点、背景不可操作、暂停与超时。另实看 320px 图片失败界面。
- SFX/BGM：真实 Web Audio 声道采样、循环、独立开关、零音量、暂停与切后台恢复；延迟音效过期及音频不可用降级。
- 发布：TypeScript、生产构建、`/xham/` 静态子目录资源和来源页返回。

验证范围是当前 Chromium 和上述自动化／手工场景，不代表所有浏览器与设备不存在问题。当前仍为 372 道配图题，清单进度 4／200 条目；本次没有增加题目，也未重新联网核验所有剧情事实。v0.11.1 公告原文归档，当前版本更新为 v0.11.2。
