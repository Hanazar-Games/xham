# v0.50.0 检查记录

日期：2026-09-21。

本轮检查题库与考试流程、UI/UX、图片恢复、键盘操作、音效和背景音乐。题量保持2322题、141套练习、45个作品专区与跨番联考；制作目录仍为43／200条目，并非全部制作完成。

## 修复与验证

- 复现成绩回顾缺少题图：完成12题练习后，回顾中的图片数量为0。现在练习、考试和历史成绩均保留题图、署名与图片来源。
- 复用现有图片失败与重试组件，回顾图片使用原生延迟加载；断图提示仅在正在计时的答题阶段提醒计时继续。
- 新增320px回顾测试，覆盖图片数量、请求失败、重试成功、焦点、来源链接、横向溢出和收起回顾；全部作品考试回归增加成绩与历史回顾的图片断言。
- 444项单元测试通过，涵盖题库结构、图片文件、来源字段、抽题、计分、暂停、超时与音频生命周期。
- 最终生产版本272项浏览器测试全部通过（4 workers，6.1分钟）：141套完整练习、45个作品各50题考试、七种屏幕尺寸、无障碍扫描、目录与筛选、收藏、历史、暂停、超时、图片恢复和声音状态切换。初次基线在90项通过后主动停止，随后重新构建并完成这一轮完整回归。
- 原生音频信号采样验证音效与BGM独立开关、循环、零音量、暂停、后台静音及恢复；关闭设置取消延迟试听，音频不可用时仍能答题。
- 生产构建与静态`/xham/`部署检查通过。
- 人工查看1440×1000首页、390×844青驱考试、320×568回顾截图；文字、图片与操作入口正常，无已观察到的遮挡或横向溢出。
- v0.49.0公告原文归档；程序比对确认旧历史未改动，锁文件仅根版本号变化。

## 检查边界

音频采用Chromium原生AudioContext与信号采样检查，不代表人工听感评价，也未覆盖所有移动浏览器。题库测试验证结构、来源字段和答题一致性，本轮没有重新逐条核查2322题的原作事实或外部来源可用性。

生产JS约1096.84 kB，gzip约401.37 kB，仍有原有超过500 kB的打包警告，未调高阈值隐藏。新增回顾图片采用按需加载，主包拆分留待独立性能优化。
