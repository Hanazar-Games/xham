# v0.80.1 全站检查记录

检查首页、专区与制作目录、搜索与筛选、收藏、练习、模拟考试、暂停退出、成绩与历史回顾、图片失败重试、键盘及IME、响应式布局、SFX与BGM生命周期。重点回归最近的Charlotte、Overlord、食戟之灵、心理测量者题库及厨房配图。

## 复现与修复

1. 特殊连字符搜索漏匹配：在首页输入 `PSYCHO‑PASS` 返回0张题卡；制作目录的规范化规则又与首页不同。先新增失败用例，再统一NFKC、大小写、空格、冒号与Unicode连接号处理。保留多词同时匹配、分段及作品范围限制。
2. 考试超时与正常提交同音：原流程无论提交还是超时都使用tap。现改为未作答超时使用timeout，选对或选错均仍使用同一tap。真实AudioContext回归分别核对超时序列、正确提交、错误提交的频率与不泄露答案的界面。
3. 手机题图来源链接点击区域过小：320px视口下实测高度15.296875px。将链接设为至少24px高并增加水平内边距；修复后实测约44.8×24px，无横向溢出。
4. 混合考试说明不够准确：跨番题池实际为简单48／中等12／困难12，完整72题无法三等分。说明改为优先均衡、某档不足时由其余难度补足。新增72题完整流程测试；测试初稿误设24／24／24，核对实际题池后修正断言，没有修改题目难度来迎合测试。

## 音频检查

真实Chromium AudioContext用例检查SFX与BGM独立声道、默认不自动播放、循环跨周期、静音与音量恢复、暂停和页面隐藏后的停止与恢复、答题反馈期间BGM降低后恢复、延迟试听取消，以及音频不可用时继续答题。单元测试另外检查异步状态竞争、过期提示、后台调度不补播积压音符、音符释放及销毁清理。

本轮调整的是考试提示的选择，没有重写音乐或修改合成音色。测量的是浏览器实际音频节点和声道信号，没有通过扬声器进行主观试听，不对听感作额外评价。

## 检查边界

浏览器自动化使用Chromium，没有覆盖所有浏览器和实体移动设备。无障碍自动规则通过不等于完成全部人工读屏审核。未重新逐一访问3772题的外部事实来源或重看作品正片；本轮题库核查侧重结构、映射、交互与图像可用性。主包体积仍是后续性能优化事项。
