# v0.2.1 检查记录

日期：2026-09-15。范围：前端架构、答题流程、UI/UX、SFX/BGM、最新与历史公告。

## 修复与验证

| 问题 | 修复与回归 |
| --- | --- |
| 异步音频启动丢提示音、快速切换可见状态后声音停住 | 串行协调音频状态，仅缓存最近 400ms 的最新提示；延迟启动与切换竞争测试通过 |
| 连续音效叠加、取消未播放音符产生声音、中途静音波形跳变 | 初始化增益、取消未来音符、按当前包络平滑结束；原生 OfflineAudioContext 波形检查通过 |
| 弹窗内部拖到外部意外关闭 | 点击必须始于并结束于遮罩；拖动、遮罩点击和 Esc 检查通过 |
| 弹窗关闭后键盘焦点丢失 | 在 DOM 移除前关闭原生 dialog；生产构建确认焦点回到打开按钮 |
| 从收藏或记录开始挑战后「探索更多」返回错误页面 | 统一回到发现页；收藏、历史重玩与历史成绩回看路径通过 |
| 辅助文字对比度不足、无效 ARIA、手机成绩标题换行不均 | 调整文字颜色、分组语义与装饰标记、平衡标题换行；相关场景复测通过 |

## 已通过的检查

- `npm test`：40 项，包含计分、重复作答、超时、暂停、音频生命周期及全部题库的计分集成。
- `npm run build`：TypeScript 检查与生产构建；`git diff --check` 无错误。
- `npm audit --audit-level=low`：0 个已知依赖漏洞。
- Chromium 实际完成全部 6 个题库、36 道题，覆盖答对、答错、真实超时、键盘操作、暂停、成绩解析、6 场记录和重新挑战。
- 搜索、分类、排序、收藏/取消、空状态、退出确认、放弃重玩不新增记录、弹窗焦点与拖动保护。
- 320、360、390、540、768、1024、1440px 视口；844×390 横屏弹窗；手机答题、解析、成绩、历史与公告没有横向溢出。
- axe-core WCAG 2 A/AA 与 2.1 AA 检查，覆盖首页、空状态、各弹窗、答题反馈、成绩解析、历史和公告；发现项修复后对应场景均无自动检测违规。
- 原生 AudioContext 确认 BGM 音频输出、循环、音量归零、独立开关、试听、暂停恢复、设置面板暂停计时；模拟 visibilitychange 快速切换，始终复用一个上下文。
- 生产构建确认 v0.2.1 最新公告与 v0.2.0 历史公告、关闭后焦点恢复、声音不可用及外部字体加载失败时仍可答题；未捕获到页面运行异常。

旧版没有独立公告文件，v0.2.0 历史内容依据该版本提交和 README 补录。运行时收藏、成绩与音频设置不写入仓库或构建产物。

验证环境为 Chromium 桌面浏览器和视口模拟；未进行 Safari、Firefox、手机真机或人工听音验收。音频结论来自生命周期、波形与原生音频采样检查，无障碍自动检查不等同于完整读屏验收。
