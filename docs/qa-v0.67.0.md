# v0.67.0 UI、UX与音频检查

本轮题量保持3122题、189套练习。检查游戏状态、弹窗、键盘焦点、声音设置、Web Audio调度、窄屏排版、图片回退及近期题库流程。

## 修复和改进

- 目录搜索框有内容时，原生search控件会处理Escape而未关闭弹窗。新增回归先复现失败，再统一Dialog的Escape处理；保留输入法组合输入保护和原有cancel路径，关闭后返回入口焦点。
- 320px截图发现10–12字选项仍使用双列，造成中文碎行。先加布局回归复现，再把手机单列触发门槛从超过12字符改为超过8字符；桌面双列保持，答题反馈仍自动滚入视口。
- 开场、正确、错误、超时与完成音效播放期间，BGM暂降至当前音乐电平的35%，结束后以0.12秒时间常数恢复。使用AudioParam自动化，不新增计时器；轻点与倒计时不降音量。停止试听、禁用SFX、零音量及隐藏页面会清除旧恢复计划。
