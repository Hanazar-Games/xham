# v0.5.0 检查记录

日期：2026-09-17。范围：2 dimention 分区首页、各作品分级题库和完整游戏回归。

## 内容与结构

- 默认首页为「2 dimention · hanazar 的二次元中心」，浏览器标题、首页文案与简写标识同步更新。
- 鬼灭之刃、海贼王、火影忍者、吉卜力电影、Re:0、芙莉莲六个专区，每区包含简单与困难两套独立的 12 题试卷。
- 新增五套进阶卷和 Re:0 人物入门卷，共 72 题。二次元合计 12 套、144 题；全站含基础主题共 18 套、180 题。
- 二次元简单题 20 秒、困难题 30 秒。原 Re:0 考核归为困难，新增简单卷的开局说明与 20 秒计时保持一致。
- 每道新题附图片、解析和来源；复用已有 64 张官方图片，没有增加图片下载体积。新增内容根据仓库中已有、附来源的设定编写，困难卷侧重职责组合、师承、因果关系与机制辨析。
- 专区、难度、关键词可组合筛选；退出专区内的挑战保留筛选。原有发现页、收藏、记录、重玩和声音功能保留。

## 验证

- 先写分区与难度覆盖测试，确认原数据六项失败；再写首页和筛选浏览器测试，确认旧页面两项失败；实现后对应测试通过。
- `npm test`：79 项通过，包含每专区两档难度、12 题、配图、来源、正确时限、唯一题目和新增试卷四个答案位置各出现 3 次。
- `npm run test:e2e`：37 项通过。生产页面完成全部 180 题，确认图片解码、正确答案、计分、回顾、记录、重玩；新增六套试卷使用 390×844 视口完成。
- 320、390、540、768、1024、1440px 和 844×390 横屏检查首页、弹窗、游戏、记录；axe-core 检查通过，未发现横向溢出。桌面首页、手机首页及专区筛选另做截图目视检查。
- 专区逐个验证两档筛选；验证搜索别名、无结果重置、返回原专区、普通题库入口和随机挑战。
- 既有真实计时、暂停恢复、图片失败与延迟、原生音频循环、静音、后台切换、过期试听、音频不可用和减少动效回归通过。
- 定位一次图片尺寸断言的偶发失败：阻塞字体与图片分别加载，确认偏移来自字体替换，图片加载前后位置相同。该测试先等待字体稳定，再检查图片占位，未放宽断言阈值。
- TypeScript 与生产构建、依赖审计、差异空白检查通过。版本更新至 v0.5.0；对象逐字段比对确认 v0.4.1 和所有旧公告完整归档。
