# v0.9.0 检查记录

日期：2026-09-17。

## 白屏根因与修复

GitHub Pages 原先以 legacy 模式发布 main 分支根目录，线上 HTML 仍引用 `/src/main.tsx` 和 `/favicon.svg`，两者均返回 404。静态服务器不能直接执行 Vite 源码入口。

新增 Actions 流程，测试通过后构建并上传 dist。部署 base 使用 Pages 返回的站点路径；动态图片、图标与本地来源链接跟随 base，原创来源页通过相对链接返回首页。开发端口固定为 5174，禁止静默换端口。

## 题库与公告

新增「身份双线索」「设定分类入门」两套简单联考，各 12 题。总计 24 套、288 题；新题沿用已有六个作品专区的资料，全部使用原创主题 SVG，不新增第三方角色图片。逐题核对答案、解析及引用，每套正确选项位置均衡。v0.8.1 公告原文归档。

## 验证结果

- 113 项 Vitest 测试通过；TypeScript 与生产构建通过。
- 49 项 Chromium E2E 通过：首次 42 项通过，7 项因公告摘要断言仍指向 v0.8.0 失败；更新为已归档 v0.8.1 后，7 项全部复跑通过。
- 所有 288 道题完成答题、图片加载、评分、回顾及重玩检查。
- 七种屏幕尺寸通过布局与无障碍检查；原生音频总线、BGM 循环、静音、暂停及后台恢复检查通过。
- 独立静态服务器无 SPA 回退，验证 `/xham/` 构建入口、全部 SVG/WebP、图标、实际答题、来源链接及返回路径；无页面异常或 HTTP 错误。
- dev-browser 检查手机新题搜索与原创封面显示。

发布流程在每次 main 更新时重跑单元、浏览器及静态部署检查。
