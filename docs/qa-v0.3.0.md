# v0.3.0 检查记录

日期：2026-09-16。范围：新增二次元题库、图片、前端答题流程、UI/UX、SFX/BGM 和版本公告。

## 题库与来源

- 新增吉卜力、Re:0、芙莉莲各 12 题，总计 9 套、72 题。逐题检查选项、答案与解析；调整吉卜力及芙莉莲的选项顺序，避免答案位置循环排列。
- 吉卜力剧情依据 GKIDS 官方影片介绍，剧照来自吉卜力官方公开图库。
- Re:0 依据动画官网角色设定与分集介绍，限第 1–2 季（第 1–50 集），每题 30 秒。重点核对帕克的火属性、加护与兽化的区别、魔女能力及圣域试炼。
- 芙莉莲依据小学馆作品与角色介绍，限第一季基础人物与设定。
- 19 张官方图片转为本地 WebP，共 733.9 KiB；生产构建内逐个确认文件格式和大小。原图地址与版权信息保存在 `public/images/anime/sources.json`，题目解析附资料链接。

## 修复与改进

| 问题 | 修复与回归 |
| --- | --- |
| `re0` 无法匹配 `Re:0`；空格组合关键词找不到相关题库 | 统一大小写与冒号写法，支持多个关键词共同匹配；搜索与清空回归通过 |
| 新增手机长选项仍被挤入两列 | 修复被基础样式覆盖的选择器；直接检查 320–1440px 的实际列数，540px 以下长选项为单列 |
| 翻题和进入成绩页残留上一页滚动位置 | 翻题与成绩页回到顶部，标题焦点保持正常 |
| 题目配图失效可能影响阅读 | 保留图片区尺寸，提供封面 SVG 和题目文字回退；拦截图片请求后仍可作答，下一题图片恢复正常 |
| 手机挑战记录辅助文字偏小，分数对比度仅 4.24:1 | 放大文字与按钮，调整记录卡片布局，加深分数字色，裁切图片圆角；七种宽度的复测通过 |
| 玩法指南固定写每题 20 秒 | 改为 20–30 秒，开局按题库显示时长，并提供剧透范围 |

## 已通过的验证

- `npm test`：50 项通过，覆盖状态机、暂停、超时、重复作答、音频生命周期、全部题库计分及新增题目与图片引用约束。
- `npm run build`：TypeScript 与生产构建通过；`npm audit --audit-level=low`：0 个已知依赖漏洞。
- Chromium 完成全部 72 题；调整后再次在生产构建完成新增 36 题，核对正确答案、解析链接、错答、真实超时、暂停、重玩和历史成绩。
- 搜索、分类横向滚动、难度排序、收藏/取消、空状态、放弃重玩不新增记录、弹窗键盘操作与焦点恢复。
- 320、360、390、540、768、1024、1440px 及 844×390 横屏；首页、开局、公告、长选项和成绩记录无横向溢出。
- axe-core WCAG 2 A/AA、2.1 AA 检查覆盖首页、新题库开局/答题/反馈/回顾、最新/历史公告；发现的手机记录页对比度问题修复后，在七种宽度复测均无自动检测违规。
- 原生 AudioContext 检查 BGM 实际采样输出、循环、音量归零、独立开关、试听、暂停恢复、设置面板暂停计时；模拟后台与快速可见性切换，复用同一个上下文且无页面异常。
- OfflineAudioContext 确认未来音符取消后无输出、活动音效平滑结束、连续触发不会累积放大。此次音频回归未发现需要修改引擎的问题。
- 生产构建在 Web Audio 不可用、外部字体请求失败和减少动效偏好下仍可答题。v0.3.0 为最新公告，v0.2.1 完整归档并保留 v0.2.0。

收藏、成绩和音频设置仅保存在运行时内存，测试状态、下载的原始网页及浏览器截图不随仓库或构建产物发布。

验证环境为 Chromium 与视口模拟，未进行 Safari、Firefox、手机真机或人工听音验收。音频结论来自生命周期、波形和原生采样；自动无障碍检查不等同于完整读屏验收。
