# v0.99.1 检查记录

本版检查 UI、交互、SFX 与 BGM，保留现有题库、计分规则及会话内设置。

- 修复音频中断时正在播放或淡出的音符仍保持连接的问题：音频时钟暂停后立即断开旧音符，正常播放时保留平滑淡出。
- 修复开发模式的 effect 清理取消开场音效后，去重标记阻止重新播放的问题；新增独立开发服务器回归。
- 320px 声音面板由内部滚动改为完整显示，音量滑块触控高度增至 44px，补充静音状态、稳定的读屏名称与计时暂停提示。
- 窄屏首页放宽正文区域，缩小并下移插画，避免单字换行及图文重叠；复查 320px、390px 截图。
- 自查发现难度选项切换时文字先变色、背景仍渐变，导致瞬间对比度不足；考试难度、题数和练习难度筛选现在同步切换颜色。
- 修正声音按钮测试的模糊定位，避免新版公告文字匹配到同名关键词；归档 v0.99.0 公告并同步版本号与 README。

验证：

- 音频中断与开发模式开场音效先添加回归、确认失败，再修复；难度切换通过冻结颜色过渡稳定复现后修复。
- `npm test`：9 个文件、838 项通过。
- 全量浏览器检查：553 项通过，1 项发现难度切换瞬间对比度不足；93 个完整 50 题考试、285 套练习及音频专项均通过。
- 修复对比度并完成最后排版调整后，重新构建并运行 17 项相关回归，全部通过；包括新增颜色切换回归、原失败项、七种视口、首页、声音面板、筛选与考试配置。
- 原生 Web Audio 验证循环、独立开关、静音、暂停、后台恢复、中断恢复及答题反馈时自动降低 BGM 音量。
- `npm run build`、`npm run test:deployment` 与 `git diff --check` 通过；子路径检查覆盖 `/xham/` 入口、图片、图标、署名、练习与考试。
- 手机声音面板 axe 检查无违规；截图复查桌面、窄屏及横屏弹窗，横向无溢出。

验证环境为 Chromium。系统中断采用状态模拟与原生 suspend/resume 验证，未做设备扬声器主观试听。构建仍提示现有主 JS 包较大。
