# v0.99.0 检查记录

本版检查 UI、交互、SFX 和 BGM，不修改题库内容或计分规则。现有 93 个作品题库与跨番联考共 4722 题、285 套练习卷。

- 专区列表限制高度并支持独立滚动、键盘操作与焦点提示。320px 手机端练习区从约 12184px 提前至 1983px，末尾专区仍可进入考试和练习。
- 小屏题面减少留白、完整缩放题图，320×568 首屏可完整看到第一排答案；长答案保持单列。
- 监听音频上下文中断，清理旧 SFX、停止 BGM 调度，恢复后只启动一个音乐循环；卸载时移除监听。
- 当前公告题量从题库计算；同步 README 和过期测试断言，从原提交恢复遗漏的 v0.97.0 公告并归档 v0.98.0。
- 自查修正样式加载顺序导致的移动端覆盖失效、公告 JSON 在 Node 环境的导入错误、滚动边缘焦点边框裁切及声音弹窗标题换行。

验证：

- 先补回归并确认失败，再修复手机选项可见性、专区浏览高度和音频中断清理。
- `npm test`：9 个文件、836 项通过。
- 针对性浏览器回归：17 项通过，含 72 题联考、所有专区筛选、真实 Web Audio 循环与静音、中断恢复和 BGM 自动压低音量。
- 全量浏览器回归 `npx playwright test --workers 6`：552 项全部通过，包含 93 个完整 50 题考试、285 套练习、七种视口、无障碍、暂停、搜索、收藏和历史记录。
- 最后调整焦点边框和声音标题后重新构建，15 项相关音频、专区与多尺寸布局回归全部通过；`git diff --check` 通过。
- `npm run test:deployment`：通过 `/xham/` 子路径入口、全部本地图片、图标、署名页和练习／考试检查。
- 浏览器截图复查手机、桌面及横屏弹窗；320px 与 1440px 首页 axe 检查无违规。

验证环境为 Chromium；系统音频中断采用上下文状态模拟及原生 suspend/resume 验证，未做设备扬声器主观试听。生产构建仍有原有的大型主 JS 包警告。
