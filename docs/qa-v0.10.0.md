# v0.10.0 检查记录

日期：2026-09-18。

## 题库与考试

- 六个现有作品专区各 50 题，分为简单 18、中等 17、困难 15。新增 84 道题均使用项目已有资料与原创 SVG 示意图，未扩展未经核对的剧情范围。
- 跨番联考另有 72 题，全站合计 372 个唯一题目 ID；24 套练习卷与扩展题共同组成题池。
- 考试支持指定难度或混合，10／20／当前范围全部题。混合卷轮流抽取各难度，耗尽的难度跳过；随机化题目和选项时保留正确答案映射，不修改原题池。
- 考试选择后锁定，超时记未作答，支持暂停。交卷前隐藏对错颜色、解析、资料链接、实时分数和对错提示音。提交后按正确率四舍五入给出百分制成绩，60 分及格，提供分难度统计、全部解析与图片来源。
- 重做同卷保留题目顺序；返回专区可以重新抽题。历史记录区分练习与考试，统一以最高正确率汇总，避免比较不同计分制原始分数。
- v0.9.0 公告原文完整归档。

## 修复与验证

- 先添加题池、抽题和计分的失败测试，再实现功能；最终 122 项单元测试全部通过。
- 57 项 Chromium E2E 全部通过，包含六个 IP 各 50 题的完整考试、全部配图加载、隐藏反馈、100 分结算、解析、重做及历史回看。
- 24 套原练习卷逐题回归；七种屏幕尺寸的布局与无障碍检查通过。
- 小屏考试设置验证题量限制、切换 IP 重置、预览关闭焦点恢复。修复考试设置小字的对比度不足。
- 全卷点击检查发现答题选项悬停位移在边界处可能反复触发，移除几何位移并保留颜色和阴影反馈；重跑完整考试通过。
- 验证考试超时、暂停及无提前答案反馈；原生 SFX/BGM 的独立开关、循环、静音、后台与暂停恢复回归通过。
- TypeScript 与生产构建通过；无 SPA 回退的 `/xham/` 静态服务器检查通过，包含入口、所有图片、图标、练习、来源页返回及新考试。
- dev-browser 实测 1440px 桌面与 320px 手机考试配置界面，无横向溢出。

当前仍为前端单人模拟考试，记录仅存在当前访问内；保留原有公开题库的资料及图片署名。
