# v0.18.1 整体回归检查

日期：2026-09-18。题库规模不变：772题、48套练习，14个作品专区及跨番联考；清单12／200条目、600／10,000题。

## 复现与修复

- 收藏页取消当前题卡后，按钮随题卡卸载，键盘焦点落回页面主体。新增键盘回归先确认失败，再修复为转到下一张或上一张题卡；当前筛选无结果时聚焦重置按钮，全部取消时聚焦返回题库按钮。复用既有焦点恢复机制。
- 音频启动被延迟时，关闭声音设置后仍可能播放未过期的试听。原有测试仅覆盖超过400ms的过期情况，本次固定测试时钟使试听仍有效，确认关闭后会错误创建三个音符。修复为声音设置卸载时取消待播音效，并用既有淡出机制停止活动音效；不停止BGM，不改变开关，也不妨碍下一次正常反馈。
