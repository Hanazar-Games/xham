# v0.4.1 检查记录

日期：2026-09-16。范围：答题状态机、题库与配图、UI/UX、SFX/BGM、版本公告。

## 复现与修复

三个问题均先加入浏览器回归测试，确认旧实现失败，再修复并验证通过：

- 390×844 屏幕上，配图题作答后「下一题」位于视口外，焦点却已经移到该按钮。现在答案锁定后将解析区滚入视野，并留出边距；翻题仍回到顶部，减少动效偏好正常生效。
- 暂停、声音和退出弹窗关闭时，原生对话框原本恢复的焦点被答题组件再次覆盖。现在仅在进入新题或首次揭晓答案时调整焦点，关闭弹窗保留触发按钮焦点。
- 音频初始化延迟超过 400ms 时，试听按钮等待 `unlock()` 后直接播放，绕过引擎的过期机制；即使关闭设置，过期试听仍会响起。现在试听立即交由引擎排队，统一丢弃过期反馈。

## 声音检查

- 使用浏览器原生 AudioContext 与 AnalyserNode 检查两条音频通道：音效与 BGM 独立开关、试听、音量归零、完整循环后的输出、暂停恢复及声音设置期间计时冻结。
- 模拟后台可见性切换及连续 10 次切换，确认上下文暂停/恢复，挑战保持暂停，恢复操作后 BGM 继续；整个过程只创建一个上下文，无页面异常。
- 模拟 Web Audio 不可用，错误提示出现，答题仍可完成。
- OfflineAudioContext 检查 tap、start、correct、wrong、timeout、tick、finish 七类提示音：均有输出，默认音量峰值约 0.015–0.112，低于削波阈值，尾音归零。
- 未改变既有曲谱、默认音量与 BGM 调度算法；本版音频修改针对过期试听。
